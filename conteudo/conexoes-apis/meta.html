META

Facebook Pages, Instagram Business, Messenger

Visao Geral

Conecte-se ao ecossistema Meta para gerenciar Facebook Pages, Instagram Business e Messenger atraves da Graph API.

Dificuldade: Media

Custo: Gratis

Auth: OAuth2 + Token

Pre-requisitos

  • Conta Facebook pessoal
  • Pagina do Facebook criada
  • Conta Instagram Business vinculada a Pagina

Passo a Passo

1

Criar App no Meta for Developers

1. Acesse developers.facebook.com
2. Clique em "My Apps" > "Create App"
3. Selecione tipo: "Business" ou "Other"
4. Preencha nome e email de contato
5. Crie o app
2

Configurar Permissoes

No dashboard do app:
1. Adicione o produto "Facebook Login"
2. Adicione o produto "Instagram Graph API"
3. Em Settings > Basic, copie:
   - App ID
   - App Secret
3

Gerar Access Token

1. Tools > Graph API Explorer
2. Selecione seu app
3. Adicione permissoes:
   - pages_show_list
   - pages_read_engagement
   - pages_manage_posts
   - instagram_basic
   - instagram_content_publish
   - business_management
4. Gere o token
5. Para token de longa duracao:
   - Access Token Debugger > Extend Access Token
4

Conectar no N8N/Make

1. Modulo Facebook/Instagram
2. Clique em "Add" connection
3. Cole App ID, App Secret e Access Token
4. Selecione a pagina/conta

Conceitos-Chave

Page Access Token

Token para gerenciar pagina

User Access Token

Token do usuario

Graph API

API principal do Meta

Business Account

Conta comercial Instagram

Limitacoes

  • Postar no Instagram requer conta Business
  • Reels tem API separada
  • Stories tem limitacoes de API
  • Rate limit: ~200 chamadas/hora
