Airtable

Passo a Passo

1. Acesse airtable.com
2. Crie conta
3. Account > Developer hub
4. Personal access tokens > Create
5. Adicione scopes necessarios
6. Copie o token

Conectar no N8N/Make

1. Modulo Airtable
2. Add connection
3. Cole o Personal Access Token
4. Selecione Base e Table

Notion

Passo a Passo

1. Acesse notion.com/my-integrations
2. Clique em "New integration"
3. Preencha: Name, Workspace, Permissoes
4. Copiar "Internal Integration Token"
5. IMPORTANTE: Compartilhe paginas com a integracao
   - Abra a pagina no Notion
   - Clique em "..." > "Connections" > sua integracao
6. Usar token no n8n

Importante

A integracao so ve paginas que voce explicitamente compartilhar com ela. Nao esqueca de adicionar a integracao em cada pagina/database!

Supabase

Backend completo com PostgreSQL, Auth, Storage e Realtime. Alternativa open-source ao Firebase.

Passo a Passo

1. Acesse supabase.com
2. Crie projeto
3. Settings > API
4. Copie:
   - Project URL
   - anon/public key (para operacoes publicas)
   - service_role key (para operacoes admin)

Google Sheets
