Apify

$5 gratis/mes

Plataforma de web scraping com Actors prontos para sites populares. Nao precisa programar - apenas configure e execute.

Passo a Passo

1. Acesse apify.com
2. Crie conta (inclui $5 creditos gratis)
3. Settings > Integrations > API
4. Copie o API Token

Conectar no N8N/Make

1. Modulo Apify
2. Add connection
3. Cole o API Token

CloudConvert

Conversao de formatos de arquivo: PDF, imagens, videos, documentos e mais.

Passo a Passo

1. Crie conta em cloudconvert.com
2. Dashboard > API > Create API Key
3. Copie a chave

Conectar via HTTP

URL: https://api.cloudconvert.com/v2/
Headers: Authorization: Bearer {API_KEY}
