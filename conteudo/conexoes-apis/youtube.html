YouTube API

Data API v3 - Videos, Canais, Playlists

Visao Geral

YouTube Data API v3 permite buscar videos, gerenciar canais, playlists e monitorar metricas. Oferece 10.000 unidades gratuitas por dia.

Dificuldade: Media

Custo: Gratis (quotas)

Auth: API Key / OAuth2

Passo a Passo

1

Habilitar API

1. Acesse Google Cloud Console
2. APIs & Services > Library
3. Busque "YouTube Data API v3"
4. Clique em "Enable"
2

Criar Credenciais

Para leitura publica (videos publicos):

1. APIs & Services > Credentials
2. Create Credentials > API Key
3. Copie a chave

Para acesso a conta (upload, gerenciamento):

1. Create Credentials > OAuth client ID
2. Siga o mesmo processo do Google Workspace
3. Adicione scopes: youtube.upload, youtube.readonly
3

Conectar no N8N/Make

1. Para API Key: use modulo HTTP com key na URL
2. Para OAuth: adicione conexao com credenciais OAuth2

Endpoints Principais

Endpoint Uso
/search Buscar videos
/videos Detalhes de video
/channels Info do canal
/playlists Listar playlists
/captions Legendas

Sistema de Quotas
