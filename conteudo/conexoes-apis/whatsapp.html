Opcao 1: Z-API (Recomendado para Iniciantes)

Passo a Passo

1. Acesse z-api.io
2. Crie conta e escolha plano
3. Crie uma instancia
4. Escaneie o QR Code com WhatsApp
5. Copie as credenciais:
   - Instance ID
   - Token
   - Security Token
6. No N8N/Make, use modulo HTTP:
   - Base URL: https://api.z-api.io/instances/{instance}/token/{token}

Endpoints Principais

POST /send-text          - Enviar texto
POST /send-image         - Enviar imagem
POST /send-document      - Enviar documento
GET  /chats              - Listar conversas
POST /send-button-list   - Enviar botoes

Opcao 2: Evolution API (Self-Hosted)

Passo a Passo

1. Provisione VPS (DigitalOcean, Contabo)
2. Instale Docker
3. Clone repositorio:
   git clone https://github.com/EvolutionAPI/evolution-api
4. Configure docker-compose.yml
5. Execute: docker-compose up -d
6. Acesse painel web
7. Crie instancia e escaneie QR Code

Sem custo mensal

Controle total dos dados

Sem limites de msgs

Opcao 3: Meta Cloud API (Oficial)

Pre-requisitos

  • - Business Manager verificado
  • - Numero de telefone dedicado
  • - Templates aprovados pelo Meta
1. developers.facebook.com > Create App > Business
2. Adicione produto WhatsApp
3. Configure numero de telefone
4. Crie e submeta templates
5. Aguarde aprovacao
6. Use API com token gerado

Conceitos-Chave

HSM (Template)

Mensagem pre-aprovada pelo Meta

Session Message

Mensagem dentro da janela de 24h

Template Message

Mensagem fora da janela 24h

Webhook

Receber mensagens em tempo real
