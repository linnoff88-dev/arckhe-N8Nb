DeepSeek

27x mais barato que GPT-4!

Passo a Passo

1. Acesse platform.deepseek.com
2. Crie conta
3. API Keys > Create
4. Copie a chave

Conectar via HTTP (Compativel OpenAI)

URL: https://api.deepseek.com/v1/chat/completions
Headers: Authorization: Bearer {API_KEY}
Body: mesmo formato OpenAI

OpenRouter

Multiplos LLMs em uma API

Fallback automatico

Billing unificado

Passo a Passo

1. Acesse openrouter.ai
2. Crie conta
3. Keys > Create Key
4. Copie a chave

Conectar via HTTP

URL: https://openrouter.ai/api/v1/chat/completions
Headers:
  - Authorization: Bearer {API_KEY}
  - HTTP-Referer: seu-site.com
Body: formato OpenAI + campo "model"

Modelos Disponiveis

OpenAI (GPT-4) Anthropic (Claude) Google (Gemini) Meta (Llama) Mistral
