Telegram

Bots, Webhooks e Automacoes

Visao Geral

Telegram oferece uma das APIs mais simples e poderosas para automacao. Crie bots com BotFather, configure webhooks e automatize notificacoes.

Dificuldade: Facil

Custo: Gratis

Auth: Bot Token

Criar Bot com BotFather 

1. No Telegram, busque @BotFather
2. Envie /newbot
3. Escolha nome do bot (ex: "Meu Assistente")
4. Escolha username (deve terminar em "bot", ex: meuassistente_bot)
5. Copie o Token gerado
   Formato: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz

Dica

Guarde o token em local seguro. Ele e a unica credencial necessaria para controlar seu bot.

Configurar Webhook

Opcao 1: Via N8N/Make

1. Adicione modulo "Telegram Bot > Watch Updates"
2. Clique em "Add" connection
3. Cole o Token do bot
4. O sistema criara o webhook automaticamente

Opcao 2: Manualmente via API

https://api.telegram.org/bot{TOKEN}/setWebhook?url={SUA_URL_WEBHOOK}
