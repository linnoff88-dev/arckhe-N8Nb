X (Twitter)

API v2 - Tweets, Mencoes, Timeline

Niveis de Acesso

Nivel Custo Tweets/mes Uso
Free $0 1.500 Teste
Basic $100/mes 50.000 Pequeno
Pro $5.000/mes 1M Profissional

Atencao

A API do X tem custos significativos. O nivel Free e muito limitado (1.500 tweets/mes). Para uso comercial, prepare-se para pagar $100+/mes no minimo.

Passo a Passo

1

Criar App

1. Acesse developer.twitter.com
2. Inscreva-se no Developer Portal
3. Crie um Project
4. Crie um App dentro do Project
5. Copie credenciais:
   - API Key
   - API Key Secret
   - Bearer Token
   - Access Token
   - Access Token Secret
2

Configurar Permissoes

Em App Settings:
1. User authentication settings > Set up
2. App permissions: Read and Write
3. Type: Web App
4. Callback URL: https://www.make.com/oauth/cb/twitter
5. Website URL: seu site
3

Conectar no N8N/Make

1. Modulo Twitter
2. Add connection
3. Cole as 4 credenciais:
   - API Key
   - API Key Secret
   - Access Token
   - Access Token Secret
4. Autorize

Limitacoes Importantes

  • API v2 tem funcionalidades diferentes da v1.1
  • Algumas features requerem planos pagos
  • Rate limits rigorosos
  • DMs requerem plano Basic ou superior
