Webhooks

Comunicaçêo em Tempo Real

Receba notificações instantâneas quando eventos acontecem

📚

O que sêo Webhooks?

Uma URL que recebe dados quando algo acontece. O sistema te AVISA, você nêo precisa perguntar.

Analogia: É como receber uma notificaçêo no celular. Você nêo fica verificando o app toda hora - ele te avisa quando algo novo acontece.

🔄

Push vs Pull

📥

PUSH (Webhook)

Sistema te avisa quando algo muda

  • ✅ Instantâneo
  • ✅ Eficiente
  • ✅ Nêo gasta execuções

🔍

PULL (Polling)

Você pergunta repetidamente se algo mudou

  • ⚠️ Delay (1-15 min típico)
  • ⚠️ Consome recursos
  • ⚠️ Gasta execuções
💰

Impacto no Custo

❌ Polling a cada 1 minuto:

60 execuções/hora × 24h = 1.440 execuções/dia

Por mês: ~43.200 execuções (só para verificar!)

✅ Webhook:

Executa apenas quando evento acontece

10 eventos/dia = 10 execuções. 4.320x mais eficiente!

🔐

Segurança de Webhooks

⚠️ Qualquer pessoa pode chamar seu webhook! Sempre valide:

🔑 Métodos de Validaçêo

  • → Secret Token: Header com token secreto
  • → HMAC Signature: Assinatura criptográfica
  • → IP Whitelist: Aceitar só IPs conhecidos
  • → Validar Payload: Checar estrutura dos dados

⚠️ Riscos sem Validaçêo

  • → Dados falsos injetados
  • → Spam de requisições
  • → Ataques de replay
  • → Execuções desnecessárias

Casos de Uso Práticos

📝 Formulários Web

Usuário submete form → webhook recebe → processa dados

💳 Pagamentos (Stripe)

Pagamento confirmado → webhook notifica → atualiza sistema

💬 Mensagens (Slack)

Nova mensagem → webhook dispara → automaçêo executa

🔧 CI/CD (GitHub)

Push no repo → webhook avisa → deploy automático

Exemplos Práticos

💳 Exemplo 1: Webhook de Pagamento (Stripe)

Quando pagamento é confirmado, libera acesso ao curso:

// 1. No N8N, criar node "Webhook" URL gerada: https://seu-n8n.com/webhook/pagamento-stripe // 2. No Stripe Dashboard, configurar webhook para essa URL Evento: checkout.session.completed // 3. Stripe envia isso quando alguém paga: { "type": "checkout.session.completed", "data": { "object": { "customer_email": "cliente@email.com", "amount_total": 29700, "metadata": { "curso_id": "n8n-pro" } } } } // 4. Workflow no N8N: Webhook → Set Node (formatar dados) → Airtable (criar acesso) → Email (boas vindas)

📝 Exemplo 2: Lead de Formulário (Typeform)

Captura lead automaticamente quando submete formulário:

// 1. Criar webhook no N8N URL: https://seu-n8n.com/webhook/leads // 2. No Typeform → Connect → Webhooks → colar URL // 3. Typeform envia quando alguém submete: { "form_response": { "answers": [ { "field": { "ref": "nome" }, "text": "Joêo Silva" }, { "field": { "ref": "email" }, "email": "joao@empresa.com" }, { "field": { "ref": "empresa" }, "text": "TechCorp" } ] } } // 4. Workflow no N8N: Webhook → Set (extrair dados) → HubSpot (criar contato) → Slack (notificar vendas)

🔐 Exemplo 3: Validaçêo de Segurança HMAC

Verificar se o webhook veio realmente do Stripe:

// Headers que o Stripe envia: { "Stripe-Signature": "t=1614556800,v1=5257a869..." } // No N8N - Code Node para validar: const crypto = require('crypto'); const secret = 'whsec_xxx'; // do Stripe Dashboard const signature = $input.first().headers['stripe-signature']; const payload = JSON.stringify($input.first().json); const expectedSig = crypto .createHmac('sha256', secret) .update(payload) .digest('hex'); if (signature.includes(expectedSig)) { return { valid: true, data: $input.first().json }; } else { throw new Error('Assinatura inválida - possível ataque!'); }

↩️ Exemplo 4: Webhook que Retorna Dados

API customizada que consulta e retorna em tempo real:

// Configuraçêo do Webhook Node: HTTP Method: POST Response Mode: When Last Node Finishes Response Data: All Entries // Sistema externo chama: POST https://seu-n8n.com/webhook/consulta-cpf Body: { "cpf": "123.456.789-00" } // Workflow: Webhook → HTTP Request (consulta API externa) → Set (formata) → Respond to Webhook // Resposta automática: { "status": "regular", "nome": "Joêo Silva", "situacao": "Ativo", "consultado_em": "2025-01-15T10:30:00Z" } // Tempo de resposta: ~500ms (síncrono!)
